### 问题分析

爬虫只爬取了一页数据就停止了，原因是`has_more_data`方法的逻辑有问题。当前逻辑是：如果当前页的posts数量小于20，就认为没有更多数据了。但实际上，这个逻辑不适用，因为：
1. 可能每页返回的数据量本来就小于20
2. 接口返回的数据中没有明显的"has_more"字段
3. 主函数中设置了`max_pages=3`，但爬虫只爬取了1页

### 修复方案

1. **修改`has_more_data`方法**：移除根据当前页posts数量判断是否有更多数据的逻辑，让爬虫能够爬取完指定的`max_pages`页数
2. **优化分页逻辑**：只有当当前页的posts数量为0时，才认为没有更多数据
3. **保留max_pages限制**：确保爬虫不会无限爬取

### 具体修改

修改`has_more_data`方法，将原来的逻辑：
```python
def has_more_data(self, data):
    if isinstance(data, dict):
        if 'posts' in data:
            posts = data['posts']
            if len(posts) < 20:
                return False
    return True
```

改为：
```python
def has_more_data(self, data):
    if isinstance(data, dict):
        if 'posts' in data:
            posts = data['posts']
            # 只有当当前页没有数据时，才认为没有更多数据
            if len(posts) == 0:
                return False
    return True
```

这样修改后，爬虫会爬取完指定的`max_pages`页数，除非遇到当前页没有数据的情况。
